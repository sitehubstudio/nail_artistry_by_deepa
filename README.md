# Nail Artistry by Deepa - Premium Studio Website

A luxury, fully responsive website for **Nail Artistry by Deepa**, located in Nirvana Country, Sector 50, Gurugram, Haryana, India.

## Folder Structure
- `index.html` - Semantic HTML5 document containing all sections (Hero, About, Portfolio, Services, Why Us, Custom Consultation, Location & Contact, Footer).
- `style.css` - Custom styling featuring soft blush, champagne gold, and ivory accents, full typography, and mobile-first media queries.
- `script.js` - Lightweight vanilla JavaScript handling mobile navigation drawer, gallery filtering, lightbox modal, and WhatsApp consultation generator.

- **Direct WhatsApp Bookings:** Configured for `+91 8083701646`.
- **Location & Google Maps:** Sector 50, Nirvana Country, Gurugram with embedded map and clickable directions.
- **Instagram Integration:** Direct links to `@nailartistrybydeepa`.
- **Zero Dependencies:** Pure HTML, CSS, and JS. Ready to host on GitHub Pages, Netlify, Vercel, or cPanel.
